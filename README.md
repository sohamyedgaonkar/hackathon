# Hackathon Project Archives

This repository stores ZIP archives of hackathon projects and experiments rather than a checked-out application source tree. The archives currently include ChromePe-related projects and MCP/server material.

Extract an archive into a separate working directory before inspecting or running it. Each archive may have its own dependencies and setup instructions; no single root-level run command is applicable. The archives have not been validated as runnable by this README review.
